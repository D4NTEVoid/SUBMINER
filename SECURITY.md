# Security Policy

## Supported versions

Security fixes are provided for the latest version on the default branch.

## Reporting a vulnerability

Please do not publish credentials, private targets, or exploitable details in a public issue.
Report suspected vulnerabilities privately to the repository maintainer using GitHub's
private vulnerability reporting feature, if enabled.

## Safe operation

SubMiner is intended for authorized security testing and asset discovery. Only scan domains
you own or are explicitly authorized to assess. The application starts on `127.0.0.1` by
default. Do not expose it to an untrusted network without adding authentication, TLS,
network access controls, and a deployment-specific security review.
